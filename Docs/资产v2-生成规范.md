# 《屏之岛》美术资产 v2（qwenimage-comic 方法论重制）

生成方法：参照 github.com/wyfirstname/qwenimage-comic《游戏素材工坊》的资产生成流水线，
将其核心方法论移植到本次生成流程：

1. **八段式提示词**：ROLE/PURPOSE → SUBJECT → VIEW → ART DIRECTION → GAME-SCALE READ → TECHNICAL OUTPUT → LOCKS → EXCLUDE，逐张组装
2. **不变块复用（家族一致性）**：美术方向八轴契约、LOCKS、EXCLUDE 三个块全素材集逐字复用；角色家族 14 张全部以同一张 master 基准图做参考图编辑（LOCK 锁定同脸/同发型/同比例/同描边/同光照）
3. **美术方向八轴契约**（单一样式锚定）：Q 版圆润形状语言、可读剪影、灰度可辨明暗、统一色彩角色（青绿环境色 + 琥珀奖励色）、统一描边宽度、单一左上光照 + 软 AO、细节集中于焦点、大平面保持干净
4. **按类画幅**：角色 2:3（768×1152）、道具/图标 1:1（768×768，白底商品图式，无环境无投影）、App 图标 1024×1024
5. **质量守门**：每张下载后 PIL 检查（尺寸≥512、像素标准差≥16 拒近纯色/黑图、均值≤248 拒全白），不过关自动换 seed 重试（101/202/303），三败后保留末次结果并登记
6. **统一负面词**：photorealistic / 3d render / painterly / text / watermark / frame / cropped edges 等

- 技能图标 12（6 元素 × 主动/被动）
- 装备图标 16（4 部位 × 布/皮/铁/机甲）
- 怪物 3、App 图标 1

## 与 v1 的差异

- v1 为一次性散点生成（每张独立提示词，风格靠形容词碰运气）；v2 全套共享同一份八轴契约 + master 基准图锚定，风格/描边/光照/画幅系统化一致
- 角色图按 2:3 全身构图（原 1:1），更适合卡牌化 UI（配合 2.5D 万智牌卡）
- 图标统一白底商品图风格（原浅奶油底），方便统一抠图做透明
- 质量守门自动重试，淘汰近纯色/全白/低熵废图

## 合入

同名替换 `Resources/Assets.xcassets` 即可（imageset 命名不变，代码零改动）。
图标如需透明底：白底商品图可用 rembg 类工具批量抠图后同名替换。
