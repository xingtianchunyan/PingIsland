# AnimationIslandLab（实验性循环动画原型）

依据：《屏之岛_iOS原生APP开发执行文档 v1.0》第 12 章。**实验增强，不是永久动画承诺。**

## 定位

- 市面上存在灵动岛简单循环动画（iScreen 笔记），但没有公开实现代码；
  “自定义字体图形＋系统计时文本”只是可测试的变通路径，不宣称是 iScreen 真实实现，
  也不当成 Apple 保证支持的正式能力。
- 正式 App 的基础保障仍是：静态关键帧＋官方数据更新短动画＋App 前台可选完整演出。
- 本工程**独立于主 App、不进 CI**，只制作 12.2 范围：一个原创角色（SF Symbol 替身）、
  两套少帧动作（走路 4 帧 / 施法 3 帧）、一个静态回退姿态、生命周期与能耗日志。

## 现状

- `LabActionController`：动作状态机，只接受外部状态驱动切换（12.4-2 门禁）。
- `CharacterView`：少帧变换动画，帧间只改位移/缩放。
- `LabLog`：时间戳日志 + 内存快照导出。
- 真实 DeviceActivity 测试事件（12.2）**未接入**——需 Family Controls entitlement
  与监控扩展，真机签名受限，列为后续项。

## 12.3 必测项（真机，结果记录到 Docs/PLATFORM_VALIDATION.md 12.3 表）

前台节奏源已就位（TimelineView 周期推进帧）。逐项记录：离开 App 后续播、真实事件切换、
8 小时生命周期、锁屏/Always-On、重启与低电量、双系统版本、性能能耗、静态回退。

## 12.4 合入门禁（当前未满足，禁止合入）

真机表现可复现 / 可靠切换 / 能耗可接受有记录 / 无私有 API / 完整静态回退 / 文档标注实验性。
只满足“能循环”则保留为摆件实验，不进正式角色生活剧场。
